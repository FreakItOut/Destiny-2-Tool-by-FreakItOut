Anleitung: API-Key

Warum braucht dieses Tool eigene Zugangsdaten, DIM aber nicht? DIM betreibt eine eigene, zentral registrierte Bungie-Anwendung mit eigenem API-Key und OAuth-Client. Diese Zugangsdaten gehören DIM, werden nicht veröffentlicht und dürfen nicht in anderen Tools wiederverwendet werden. Deshalb braucht dieses Tool eine eigene kostenlose Bungie-Anwendung: API-Key + OAuth-Client-ID, das Client-Secret nur für dauerhaftes Angemeldetbleiben.

  1. Auf bungie.net anmelden (dein Destiny-Konto).
  2. Direkt zur Anwendungen-Seite: https://www.bungie.net/de/Application (oder unten auf der Seite „API“ klicken).
  3. Auf „Neue Anwendung erstellen“ / „Create New App“ klicken.
  4. Felder ausfüllen: Name (z. B. „Mein D2 Tool“), Website darf leer bleiben.
  5. Bei OAuth: „Nicht einsehbar“ wählen – das reicht für die Dashboard-Daten (Hüter, Aktionen, News). Wer sich anmelden will (Inventar & Loadouts), braucht stattdessen „öffentlich“ – siehe nächste Anleitung.
  6. Erstellen → in der App-Übersicht steht der API-Key („API Key“-Zeile). Den 32-stelligen Schlüssel kopieren.
  7. Schlüssel hier einfügen + deinen Bungie-Namen (mit #Nummer) eintragen → „Daten testen“.

Wichtig: Damit das Dashboard deine Hüter sieht, muss dein Bungie-Profil öffentlich sichtbar sein: bungie.net → Profil → Privatsphäre-Einstellungen → „Verbindungsdaten/Licht“ auf öffentlich.

Anleitung: OAuth-Client
  1. Auf bungie.net anmelden → https://www.bungie.net/de/Application → „Neue Anwendung erstellen“.
  2. Name: frei (z. B. „Mein D2 Tool“).
  3. Website: exakt https://localhost eintragen (dieser Wert muss auch im Feld „Origin“ hier im Tool stehen — Standard ist bereits richtig).
  4. Bei OAuth: „Vertraulich“ wählen (englisch „Confidential“). Dadurch erscheinen „OAuth Redirect-URL“ (dort https://localhost) und das „OAuth Client Secret“.
  5. Bei den Bereichen (Scope): beide Destiny-Scopes ankreuzen – „ReadDestinyInventoryAndVault“ (Tresor & Beutetasche lesen) und „MoveEquipDestinyItems“ (verschieben/ausrüsten). Ohne das Lesen-Scope bleiben Tresor und Beutetasche leer!
  6. „Ich stimme zu“ ankreuzen → Erstellen.
  7. In der App-Übersicht „OAuth 2.0 Client ID“ (Zahlenfolge) und „OAuth Client Secret“ kopieren → beide oben einfügen.
  8. „Anmelden …“ drücken → Bungie-Fenster → „Autorisieren“. Danach erneuert sich die Anmeldung automatisch (Refresh-Token).

Warum „Vertraulich“? Bungie stellt öffentlichen Apps bewusst keinen Refresh-Token aus (offizielle OAuth-Doku). Dann gilt die Anmeldung nur ca. 1 Stunde und endet mit „Anmeldung abgelaufen“. Mit Client-Secret bleibt das Tool dauerhaft angemeldet. Scopes erst NACH einer Anmeldung geändert? Einmal Abmelden → Anmelden (Abmelden widerruft die alte Autorisierung).

Inventar & Loadouts (Bungie)

  1. Einstellungen → Bungie: API-Key setzen und anmelden (OAuth) — erst danach ist das Inventar verfügbar.
  2. 🎒-Knopf (oder Palette „Inventar öffnen“) öffnet das Panel: Angelegt, Beutetasche und Tresor pro Hüter, durchsuchbar.
  3. Transfer mit „→ Tresor“ bzw. „→ Titan/Jäger/Warlock“ direkt aus der Liste.
  4. Loadouts sichern: Charakter wählen, Namen eintippen, „Loadout sichern“ — die aktuell angelegten Items werden gespeichert.
  5. Loadout anlegen: „Anlegen“ holt die Items zurück (Transfer + Ausrüsten automatisch). Bungie kann abstoßen (z. B. zweites Exotic, Item bei anderem Hüter) — die Meldung erscheint als Toast.

Für Transfers muss deine Bungie-App-Registrierung das Scope „MoveEquipDestinyItems“ erlauben. Der erste Inventar-Laden zieht einmalig die Item-Definitionen (danach gecacht).
